Layered architecture

  1. Presentation layer: HTML and CSS display the form and response.
  2. Client layer: JavaScript validates input and sends an HTTP POST request with JSON.
  3. Server layer: Python receives the request, validates it, and creates a JSON response.
  4. Transport/network layer: HTTP over TCP/IP carries data through localhost (127.0.0.1).
Runs locally on this computer. No external service or database required.
